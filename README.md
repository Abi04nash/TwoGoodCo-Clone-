# 🖥️ TooGood Co Webpage UI Clone

A **high-fidelity UI clone** of the TooGood Co official website, built using **HTML, CSS, JavaScript**, and enhanced with **GSAP animations** and **Locomotive Scroll** for smooth user experience.

> This project replicates the unique and elegant design of TooGood Co, focusing on layout precision, scroll-based animations, and responsive behavior.

---

## 🔗 Live Demo

👉 [View the Live Site](https://abi04nash.github.io/TwoGoodCo-Clone-/)

---

## 🎯 Features

- ✨ Smooth scroll animations using **Locomotive Scroll**
- 🎞️ Scroll-triggered effects powered by **GSAP**
- 🌗 Light/Dark Mode toggle
- 📱 Fully responsive design
- 🎨 Modern UI with pixel-perfect layout
- 🧩 Interactive elements & transitions

---

## 🛠️ Technologies Used

| Technology       | Purpose                        |
|------------------|---------------------------------|
| HTML             | Structure of the webpage        |
| CSS              | Styling and layout              |
| JavaScript       | Interactivity                   |
| GSAP             | Scroll-based animations         |
| Locomotive Scroll / ScrollTrigger | Smooth scrolling & triggers |
